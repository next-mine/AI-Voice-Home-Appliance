# AI-Voice-Home-Appliance
基于 ESP32 的 AI 语音智控家电改造模块（“源力基石”计划申报项目）

项目简介
本项目旨在开发一款低成本的智能语音改造模块。无需拆解传统家电，仅需通过红外发射管或继电器即可让老式空调、风扇等接入 AI 语音控制系统，解决存量家电智能化升级成本高的问题。

核心功能
语音控制：通过离线语音模块（如 SU-03T）实现基础指令识别

AI 对话：联网状态下接入大模型 API，支持自然语言交互控制

主动智能：结合温湿度传感器，实现“觉得热了自动降温”等场景

技术方案
主控芯片：ESP32

语音交互：SU-03T（离线） + 大模型 API（联网）

执行机构：红外发射管 / 继电器模块

感知模块：温湿度传感器

阶段任务规划
第 1 周：方案确认与物料采购

第 2-3 周：硬件组装与基础离线语音调试

第 4-5 周：接入大模型 API，优化主动决策逻辑

第 6 周：外壳 3D 打印、整体联调、录制演示视频

项目状态
项目现处于立项阶段，后续将通过 GitHub 持续开源硬件设计与软件代码。
